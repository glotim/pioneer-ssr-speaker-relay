# Hardware files

## kicad/

The KiCad 10 project for the card (rev A, as built).

- `relay-ssr.kicad_pro`, `.kicad_sch`, `.kicad_pcb`: the project, schematic and
  layout.
- `ssr.kicad_sym`: project symbol library (the Si8752).
- `ssr.pretty/`: project footprint library (the lap-soldered wire pins
  `LAP_PIN_18AWG` and `LAP_PIN_20AWG`).
- `sym-lib-table`, `fp-lib-table`: point KiCad at the two project libraries
  using `${KIPRJMOD}`, so the project opens anywhere.
- `ssr_small.kicad_wks`: the drawing-sheet border.
- `fabrication-toolkit-options.json`: settings for the Fabrication Toolkit
  plugin that produced the files in `jlcpcb/`.

Other parts come from KiCad's standard libraries. The 3D models use
`${KICAD10_3DMODEL_DIR}`.

## jlcpcb/

Production files generated by the Fabrication Toolkit plugin, ready to upload.

- `relay-ssr-gerbers.zip`: Gerbers and drill files (upload this as the PCB).
- `bom.csv`: bill of materials with LCSC part numbers.
- `positions.csv`: component placement (CPL). P1–P6 are the wire-pin pads;
  they are not in the BOM and are not placed.
- `designators.csv`, `netlist.ipc`: extra files from the plugin; JLC accepts
  the netlist for checking.

**BOM note:** U1's LCSC number (C17282409, the reel version of the Si8752AB-IS)
was added by hand after export; the schematic field is empty. On the first
order, C1/C2 and D1 were out of stock and were substituted with KEMET
C0805C100J1GACTU (C6371538) and BZT52C15 (C2104). Check stock when you order.

Settings used: 2 layers, 1.6 mm FR-4, 1 oz copper, HASL (lead-free), top-side
assembly.
